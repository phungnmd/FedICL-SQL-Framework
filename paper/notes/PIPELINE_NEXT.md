# FedLS-SQL — active protocol-v2 queue

## P2.4c — matched two-epoch public training

Run from the Windows server `fedicl-sql/` root. Required nested ancestor:
`ccb3e91`. Sync before starting either GPU; keep Git unchanged while either
lane runs. Exact reruns use the same outputs to resume/skip.

Priority: test whether one public epoch was insufficient. P2.4a's small,
nonsignificant Hinton difference does not prove equivalence or rule out a
depth effect. The [terminal SeqKD queue](../archive/completed_runbooks/P24_SELECTED_TERMINAL_DEFERRED_2026-09-16.md)
is deferred, not rejected.

Both lanes start from the same pure-FL T1 adapter and train two full public
epochs from step zero on all 9,428 BIRD rows with evidence. CE uses weight 1;
Hinton uses 0.5 CE + 0.5 forward KL, T=2, reusing the existing cache. This
compares the full recipes, including CE weight. Every private A stays one
local epoch. New roots preserve the old one-epoch experiments.
