# FedLS-SQL — active protocol-v2 queue

> Run from the `fedicl-sql/` repository root on the Windows experiment server.
> Every PowerShell block is one physical line and owns all variables it uses.
> Exact reruns resume/skip under immutable roots. Do not change Git while a GPU
> command is running. Publication remains a separate operator action.

## Current order

| Order | Action | Gate |
|---:|---|---|
| 1 | `A>K[ce]>A` plus five-set eval | isolate whether soft teacher logits survive terminal consolidation |
| 2 | Publish and compare with `A>K[fkl]>A` | recurrent Hinton opens only if logits retain useful EX |
| 3 | GPU 0: `A>K2`; GPU 1: `A>K>A>A` | separate extra public KD from extra private/FedAvg training |
| 4 | Publish phase 1 | every derived stage parent must be committed |
| 5 | GPU 0: `A>K2>A`; GPU 1: `A>K>A>K` | compare continuous KD depth with the intermediate recurrent checkpoint |
| 6 | Publish phase 2 and decide | open `A>K>A>K>A`/`A>A>A` only if the measured trajectories justify them |

## P2.4b — KD-depth and schedule screen (conditional)

Keep every private `A` at one local epoch. `K2[fkl]` is an explicit two-epoch
public stage planned from step zero with the same 9,428-row cache; it adds no
client communication. Required nested code: `fca5eef` or a descendant.

The first measurements separate `A>K2` from `A>K>A>A`. After publication,
append one private stage to K2 and compare `A>K2>A` with intermediate
`A>K>A>K`. Only then decide whether the final recurrent `A` and pure-FL
`A>A>A` are warranted. Multi-local-epoch `A[e2/e3]` is closed.
