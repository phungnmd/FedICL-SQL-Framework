Method

Một câu: client không chỉ có nhãn mà còn có database để chạy SQL; FedAvg SFT dùng nhãn, method dùng cả hai.

Method là k round FedAvg SFT, rồi các round DPO + NLL on-policy với nhãn từ việc chạy SQL ở client; k = 2. Thiết kế của owner. Công trình gần nhất: CodeLutra (arXiv 2411.05199), một vòng lặp tương tự chạy centralized. Federated DPO as published: OpenFedLLM (arXiv 2402.06954), pairs làm một lần và reference cố định.

Một round DPO + NLL

  1. Server gửi global model của round.
  2. Mỗi client sample 10 SQL cho mỗi câu hỏi của mình (T 1.0), chạy trên database của mình, so kết quả với gold.
  3. Câu có cả SQL đúng và sai cho 2 pairs (đúng, sai) rút ngẫu nhiên. Câu toàn đúng, toàn sai, hoặc trên database không có rows thì không cho pair ở round này.
  4. Client train DPO + NLL trên SQL đúng; reference của DPO là global model của round.
  5. Server lấy trung bình adapter LoRA, trọng số theo số pairs. Chỉ adapter rời client.

Viền cam: chạy ở client, dữ liệu không rời client. Round sau sample lại từ global model mới, nên lỗi của model mới được tìm lại mà không thêm communication.

Prompt

Một prompt cho train, sample và eval: prompt Text-to-SQL của code đánh giá Qwen2.5-Coder, một user message qua chat template của model. Schema: CREATE TABLE và 3 rows mẫu mỗi bảng trên Spider (ddl_rows); CREATE TABLE không rows trên BIRD (ddl). Target khi train: gold SQL bỏ dấu ; cuối, rồi token kết thúc lượt.

Spider
{CREATE TABLE ... và 3 rows mẫu mỗi bảng}

-- Using valid SQLite, answer the following questions for the tables provided above.
Question: {câu hỏi}

Please output only the final SQL query, starts with keyword `SELECT`.
BIRD, có evidence
{CREATE TABLE ...}

-- External Knowledge: {evidence}

-- Using valid SQLite and understanding External Knowledge, answer the following questions for the tables provided above.

Question: {câu hỏi}

Please output only the final SQL query, starts with keyword `SELECT`.

Nguồn: fedls_sql/prompts/builder.py. Đọc SQL từ output: khối code nếu có, cắt ở dấu ; đầu tiên, từ SELECT đầu tiên.

FedAvg SFT
lr 2e-4, 1 local epoch mỗi round, batch 1 với gradient accumulation 16; FedAvg theo số câu hỏi
Centralized SFT
cùng recipe trên dữ liệu 5 client gộp, theo epoch
Round DPO + NLL
10 samples ở T 1.0, 2 pairs mỗi câu rút ngẫu nhiên, beta 0.1, NLL weight 1, lr 5e-5, 1 epoch, weight decay 1e-4; reference là global model của round; FedAvg theo số pairs. Theo CodeLutra, trừ số pairs mỗi câu và LoRA r 16 (CodeLutra r 8)
