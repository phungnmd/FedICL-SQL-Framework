Organizations can train a shared small language model (SLM) for Text-to-SQL by federated learning with low-rank adaptation (LoRA), but federated averaging with supervised fine-tuning (FedAvg SFT) learns from gold SQL queries and federated direct preference optimization (FedDPO) from fixed preference pairs against a fixed reference model, so neither executes the queries of the current model on the client databases. A client can execute queries sampled from the model on its own databases and label each one correct or incorrect against the result of the gold SQL query. We propose \method, a federated learning framework for Text-to-SQL that trains on these labels. After warm-up rounds of FedAvg SFT, each client in a preference round samples queries from the current global model, labels them by execution, and trains on pairs of a correct and an incorrect sample with a negative log-likelihood term and a direct preference optimization term with that model as reference. With \setting{model}, \method{} reaches \ex{bird}{k2}{4}\% execution accuracy (EX) on BIRD dev and \ex{spider}{k2}{4}\% on Spider test, \gap{bird}{fedavg}{4}{k2}{4} and \gap{spider}{fedavg}{4}{k2}{4} points above FedAvg SFT at the same number of rounds. On BIRD dev, it is also above FedDPO run on the first execution-labeled pairs of \method. Against FedAvg SFT, execution errors fall by about half on both benchmarks. A client sends the same adapter as in FedAvg SFT in every round, so communication is unchanged, and the preference rounds add client computation for sampling, labeling and training.
