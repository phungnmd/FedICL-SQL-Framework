Federated learning with low-rank adaptation (LoRA) enables organizations to fine-tune a shared small language model (SLM) for Text-to-SQL while keeping private databases and annotated questions on-premise. However, federated averaging with supervised fine-tuning (FedAvg SFT) computes negative log-likelihood (NLL) only on each question's gold SQL query and never executes model queries on client databases. Conversely, federated direct preference optimization (FedDPO), which applies direct preference optimization (DPO) to general preference alignment, trains on static external response pairs under one fixed reference model across rounds. We propose \method, a federated learning framework for Text-to-SQL that derives supervision from client-side query execution. After \setting{rounds.warmup} supervised warm-up rounds, \method{} runs \setting{rounds.pref} preference rounds in which each client samples SQL queries from the current global model and executes them locally against the gold SQL result. Clients construct renewed on-policy preference pairs every round and minimize a DPO loss relative to that round's global model plus a token-averaged NLL term on the correct sample of each pair. Across five non-independent and identically distributed (non-IID) clients with \setting{model} (\setting{model.size} parameters) at \setting{rounds.total} communication rounds, \method{} reaches \ex{bird}{k2}{4}\% execution accuracy (EX) on BIRD dev and \ex{spider}{k2}{4}\% EX on Spider test. These scores exceed FedAvg SFT (\ex{bird}{fedavg}{4}\% and \ex{spider}{fedavg}{4}\%) by \gain{bird}{fedavg}{4}{k2}{4} and \gain{spider}{fedavg}{4}{k2}{4} EX points, while evaluation execution errors fall from \nerr{bird}{fedavg}{4} to \nerr{bird}{k2}{4} and from \nerr{spider}{fedavg}{4} to \nerr{spider}{k2}{4}. Because samples, execution labels, and pairs stay on-premise and clients upload only a \setting{adapter.mb} adapter and an integer weight per round, \method{} turns client databases into supervision at unchanged communication cost.
