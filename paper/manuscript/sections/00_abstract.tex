Federated learning with low-rank adaptation (LoRA) enables organizations to fine-tune a shared small language model (SLM) for Text-to-SQL while keeping private databases and annotated questions on-premise. However, federated averaging with supervised fine-tuning (FedAvg SFT) computes negative log-likelihood (NLL) only on each question's gold SQL query and never executes model queries on client databases. Conversely, federated direct preference optimization (FedDPO), which applies direct preference optimization (DPO) to general preference alignment, trains on static external response pairs under one fixed reference model across rounds. We propose \method, a federated learning framework for Text-to-SQL that derives supervision from client-side query execution. After \setting{rounds.warmup} supervised warm-up rounds, \method{} runs \setting{rounds.pref} preference rounds in which each client samples SQL queries from the current global model and executes them locally against the gold SQL result. Clients construct renewed on-policy preference pairs every round and minimize a DPO loss relative to that round's global model plus a token-averaged NLL term on the correct sample of each pair. Across \fact{split.bird.a0.1.k5.clients} non-independent and identically distributed (non-IID) clients with \setting{model} (\setting{model.size} parameters) at \setting{rounds.total} communication rounds, \method{} reaches \ex{bird}{k2}{4}\% execution accuracy (EX) on BIRD dev and \ex{spider}{k2}{4}\% EX on Spider test. These scores exceed FedAvg SFT (\ex{bird}{fedavg}{4}\% and \ex{spider}{fedavg}{4}\%) by \gain{bird}{fedavg}{4}{k2}{4} and \gain{spider}{fedavg}{4}{k2}{4} EX points, and on BIRD dev we obtain gains of \gain{bird}{feddpo}{4}{k2}{4} EX points and \tsgain{bird}{feddpo}{4}{k2}{4} test-suite accuracy points over FedDPO trained with the fixed execution-labeled pairs of \method's first preference round. Relative to FedAvg SFT, execution errors fall from \nerr{bird}{fedavg}{4} to \nerr{bird}{k2}{4} on BIRD dev and from \nerr{spider}{fedavg}{4} to \nerr{spider}{k2}{4} on Spider test. Because samples, execution labels, and pairs stay on-premise and clients upload only a \setting{adapter.mb} adapter and an integer weight per round, \method{} turns client databases into supervision at unchanged communication cost.
