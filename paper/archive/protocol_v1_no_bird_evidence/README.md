# Protocol v1 archive — BIRD evidence omitted

These files preserve the project state before the 2026-09-03 protocol reset.
BIRD `evidence` was stored but omitted from all prompts. BIRD officially permits
a without-knowledge setting, so these artifacts remain useful as historical
no-knowledge results and diagnostics. They are not canonical protocol-v2 paper
evidence.

Do not edit archived commands or reuse their output roots. Server artifacts are
retired through `fedicl-sql/scripts/retire_protocol_artifacts.py`; the default is
dry-run and the apply action quarantines rather than deletes.
