What's actually shipping

  • SC-vote (N=8, k=0) is the default inference overlay — beat the gated-retry overlay, McNemar p=0.00042.
  • RKD is the provisional KD direction — rkd−ft = +6.09 EX, p=3.1e-07.
  • Pool P = BIRD schemas/DBs only — BIRD's own gold SQL is banned as a training target.
  • Demo content doesn't matter on a trained student — random ≈ DAIL, McNemar p=1.00.
  • Only LoRA adapters cross the wire — no formal DP claim, no "no weights leave" claim.
