# FedLS-SQL: EX results (updated 2026-10-28)

Setup: Spider private (5 clients, domain-cluster Dirichlet split, alpha 0.1),
BIRD public (9,428 rows, with evidence) at the server, frozen teacher
Qwen2.5-Coder-7B-Instruct (server only). Student Qwen2.5-Coder-1.5B-Instruct +
LoRA r16, sample-weighted FedAvg. EX (%), greedy, no ICL. Seed 0. Spider test
(2,147 questions) is the confirmation set; Spider dev, its three variants and
BIRD dev are the development sets.

Method (`mixkd50_k2aaa`):

1. Server warm-start: distillation on BIRD with 0.5 gold CE + 0.5 KL to the
   teacher (Hinton KD, T=2).
2. Federated rounds: FedAvg on Spider. In every round each client also
   trains on BIRD replay rows (20% of its private row count, drawn from a
   fixed 2,000-row subset) with 0.5 gold CE + 0.5 KL to the teacher's top-50
   tokens plus one tail bucket (T=2). The server ships these teacher targets
   once (about 33 MB per client); the teacher never runs at the clients.

Training settings: warm-start 2 epochs over BIRD; 3 FedAvg rounds of 1 local
epoch; lr 2e-4 for every stage. Communication: the LoRA adapter has
18,464,768 parameters, 73.9 MB in fp32 per client per direction per round.

Comparators:

- Server KD / gold CE warm-start + FedAvg: step 1 with or without the
  teacher, then plain FedAvg rounds.
- Replay with gold CE: the same replay rows with gold CE only.
- Matched pipeline without teacher: server gold CE, then replay with gold CE.
- Same replay rows at the server: server KD warm-start, one more server KD
  stage on exactly the rows the clients replay (5,193), then plain rounds.
- Server steps between rounds: FSL-style (Mai et al., IEEE TAI 2024).
- Virtual teacher: smoothing-only teacher (Yuan et al., CVPR 2020).
- Execution-filtered replay: the method with the replay subset drawn from
  the 5,319 BIRD rows whose teacher SQL executes to the gold result.

## Notes

- The method was selected among 17 federated configurations of the 1.5B
  student, each evaluated per round on Spider and BIRD dev and at the final
  round on all five development sets.
- All numbers are one seed. The three-seed confirmation on Spider test (the
  method against the matched pipeline without teacher, server KD
  warm-start + FedAvg, the same replay rows at the server, a FedCoLLM-style
  schedule, FedAvg and server gold CE warm-start + FedAvg) is running.
- The seed-0 Spider test rows, the execution-filtered replay and the SynSQL
  rows are recorded on the GPU server; their publication to the code
  repository is pending.
- 0.5B and 1.5B use different client splits (alpha 0.5 vs 0.1); compare
  within a table, not across.
