# FedLS-SQL: EX results (2026-10-26)

Setup: Spider private (5 clients, domain-cluster Dirichlet split, alpha 0.1),
BIRD public (9,428 rows, with evidence) at the server, frozen teacher
Qwen2.5-Coder-7B-Instruct (server only). Student Qwen2.5-Coder-1.5B-Instruct +
LoRA r16, sample-weighted FedAvg. EX (%) on dev sets, greedy, no ICL. Seed 0,
exploratory (not yet confirmed).

Method (`mixkd50_k2aaa`):

1. Server, K2: 2 epochs on BIRD with 0.5 gold CE + 0.5 KL to the teacher
   (Hinton KD, T=2).
2. Clients, AAA: 3 FedAvg rounds on Spider. In every round each client also
   trains on BIRD replay rows (20% of its private row count, drawn from a
   fixed 2,000-row subset) with 0.5 gold CE + 0.5 KL to the teacher's top-50
   tokens plus one tail bucket (T=2). The server ships these teacher targets
   once (about 33 MB per client); the teacher never runs at the clients.

Comparators:

- K2AAA, server Hinton KD / gold CE: step 1 with or without the teacher,
  then plain FedAvg rounds.
- Replay with gold CE: the same replay rows with gold CE only.
- Matched pipeline without teacher: server gold CE, then replay with gold CE.
- Same replay rows at the server: K2, one more server Hinton stage on exactly
  the rows the clients replay (5,193), then plain rounds.
- Server steps between rounds: FSL-style (Mai et al., IEEE TAI 2024).
- Virtual teacher: smoothing-only teacher (Yuan et al., CVPR 2020).

## Notes

- One seed on dev sets. The method was selected among 16 federated
  configurations of the 1.5B student, each evaluated per round on Spider and
  BIRD dev and at the final round on all five sets. Claims need the planned
  3-seed confirmation on Spider test (2,147 rows).
- 0.5B and 1.5B use different client splits (alpha 0.5 vs 0.1); compare
  within a table, not across.
- Running: the method with replay restricted to the 5,319 BIRD rows whose
  teacher SQL executes to the gold result.
