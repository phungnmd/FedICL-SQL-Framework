# FedLS-SQL: EX results (2026-10-22)

Setup: Spider private (5 clients, domain-cluster Dirichlet split), BIRD public
(9,428 rows, with evidence) at the server, frozen teacher
Qwen2.5-Coder-7B-Instruct (4-bit, server only). Student + LoRA r16, FedAvg.
EX (%) on dev sets, greedy, no ICL. Seed 0, exploratory (not yet confirmed).

Method (K2AAA): 2 server epochs on BIRD, then 3 FedAvg rounds on Spider.

- Server Hinton KD = 0.5 gold CE + 0.5 KL, T=2.
- Server gold CE = same schedule, no teacher.
- Virtual teacher = smoothing-only teacher (Yuan et al., CVPR 2020).
